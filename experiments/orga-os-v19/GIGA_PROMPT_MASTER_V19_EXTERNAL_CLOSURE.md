# GIGA-PROMPT V19 — EXTERNAL CLOSURE ONLY, NIVEAU DARPA

## Verrou philosophique

ORGA-OS/SOCU vise un organisme computationnel : cognition, exploitation du corps,
mémoire et apprentissage appartiennent à une même histoire causale. Mais V19 ne
cherche plus à refaire gagner ce paradigme dans un nouveau simulateur. Elle ferme
uniquement les preuves externes absentes de V18 pour le mécanisme AERA.

## Interdictions

- Aucun nouveau contrôleur SOCU.
- Aucun changement de métrique après observation des résultats.
- Aucune revendication de supériorité générale sur Linux, Windows, MPC ou POMDP.
- Aucun passage FPGA si une seule gate est rouge.
- Deux runners GitHub ne doivent jamais être présentés comme une reproduction
  humaine ou organisationnelle indépendante.

## Mission

1. Exécuter TLC sur le modèle fixe, le modèle mutant et la rotation de certificat.
2. Exiger un contre-exemple du mutant ; son passage est un échec.
3. Épingler QEMU 11.0.2 au commit exact.
4. Compiler le périphérique AERA sur Ubuntu 22.04 et 24.04.
5. Exécuter les six QTests : probe, reset/commit, replay+IRQ perdue, MMIO invalide,
   hot-swap et reset système.
6. Exécuter `iommu-riscv-test` sur les deux runners.
7. Archiver logs, versions, binaires et empreintes, même lorsqu'une gate échoue.
8. Produire une décision PASS/FAIL sans masquer les erreurs brutes.

## Comités simulés

Méthodes formelles, concurrence, QEMU/QOM/SysBus, RISC-V/IOMMU, runtime assurance,
red-team replay/reset/MMIO, supply-chain, reproductibilité, comité de destruction.
Ce sont des perspectives simulées, jamais une validation DARPA ou IEEE.
